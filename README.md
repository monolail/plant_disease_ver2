# 병충해 진단 프로그램 제작 ver2

----------------

## 프로젝트 소개
>이 프로젝트는 병충해 진단 서비스를 애플리케이션으로 구현해봄으로써 일반인들이 간편하고, 편리하게 농사와 같은 업무에 도움이 되고자 개발하였다.

## 진행 과정
### 1. 주제 선정 이유
> 휴대폰에서 앱을 통해 간단하게 식물의 상태를 알아보고 사용자에게 유용한 정보를 제공할 수 있는 앱을 구현하고자 하였다.

### 2. 사용한 데이터 및 언어&플랫폼
> 선정한 데이터
* 'kaggle'에서 가져온 [New Plant Diseases Dataset](https://www.kaggle.com/datasets/vipoooool/new-plant-diseases-dataset?resource=download)을 참고하여 식물의 상태에 대한 정보를 제공하였다.

> 선정한 언어
1. Python 
  *  파이썬은 Google Colab을 통해 병충해 진단에 필요한 AI 모델을 만들고 학습시키는데 사용.

2. Dart/Flutter
  *  모델의 진단 결과를 사용자에게 보여주는 크로스 플랫폼 모바일 앱 (사용자 인터페이스)을 만드는 데 사용.

> 선정한 플랫폼
1. Google colab
  *  딥러닝 모델 개발 및 학습 환경 제공하고, 병충해 진단 모델(CNN 등)을 효율적으로 구축하고 학습시킬 수 있기에 사용.

2. VSCODE
  *  Flutter 확장 기능을 사용하여 병충해 진단 앱의 Dart 코드 작성, 디버깅, 실시간 미리보기(Hot Reload) 등의 기능으로 효율적인 크로스 플랫폼 앱 개발이 간편.

### 3. 프로젝트 진행 순서
> 병충해 진단 앱 개발 프로젝트 진행 과정
1. 데이터 확보 및 준비 : AI 모델 학습을 위한 데이터셋 준비

2. 모델 구축 및 학습 : 병충해 이미지를 인식하고 분류하는 AI 모델 형성

3. 모델 최적화 및 저장 : 학습된 모델을 실제 서비스 환경에 맞게 변환
  
4. 앱 개발 및 UI/UX 구현 : 사용자가 상호작용할 수 있는 인터페이스 개발

5. 모델 연동 및 테스트 : 앱이 백엔드/API를 통해 모델을 성공적으로 호출하는지 확인

6. 최종 테스트 및 배포 : 전체 시스템의 안정성과 사용자 경험 검증 후 앱 배포

> 동작 설명

## 1. 앱 실행 및 초기 화면 구성

**1.1 안내 문구 영역**

<앱 실행 시 화면 상단에 고정된 안내 문구 표시>

문구 내용:

  *  “진단을 원하시거나, 식물 상태가 궁금하신 사진을 찍어 업로드해주세요.”
  *  사용자의 행동을 유도하는 역할 수행

**1.2 이미지 표시 영역**

  *  안내 문구 하단에 위치
  *  사용자가 선택하거나 촬영한 이미지를 미리 확인할 수 있는 영역
  *  초기 상태에서는 빈 화면 또는 기본 플레이스홀더 이미지 표시
    
## 2. 이미지 입력 방식 선택

**2.1 버튼 구성**

이미지 표시 영역 하단에 다음의 세 가지 버튼 배치:

  *  카메라 촬영 버튼

  *  갤러리 업로드 버튼

  *  진단하기 버튼

**2.2 카메라 촬영 기능**

사용자가 카메라 촬영 버튼 클릭 시:

  *  기기 카메라 실행

  *  식물 사진 촬영

촬영 완료 후:

  *  촬영한 이미지가 이미지 표시 영역에 즉시 렌더링됨

**2.3 갤러리 업로드 기능**

사용자가 갤러리 업로드 버튼 클릭 시:

  *  기기 갤러리 접근

  *  기존 저장된 이미지 선택

이미지 선택 완료 후:

  *  선택된 이미지가 이미지 표시 영역에 즉시 렌더링됨

## 3. 진단 요청 및 모델 분석

**3.1 진단하기 버튼 동작**

  *  이미지가 선택 또는 촬영된 상태에서 활성화

사용자가 진단하기 버튼 클릭 시:

  *  입력된 이미지가 AI 진단 모델로 전달됨

**3.2 이미지 분석 과정**

  *  모델이 식물 이미지를 분석

  *  병충해 여부 또는 정상 상태 판단 수행

  *  예측 결과 및 신뢰도 계산

## 4. 진단 결과 출력 영역

**4.1 기본 진단 결과 표시**

  *  분석 완료 후 진단 결과 섹션 표시

포함 정보:

  *  질병명 또는 건강 상태(정상/이상)

  *  예측 신뢰도(%)를 텍스트 형태로 제공

**4.2 결과 정보 가독성**

  *  핵심 결과(질병명, 건강 여부)를 강조 표시

  *  신뢰도는 보조 정보로 함께 제공

## 5. 외부 정보 탐색 기능

**5.1 외부 링크 버튼 제공**

  *  진단 결과 하단에 배너 형태의 버튼 제공

  *  사용자가 추가 정보를 즉시 탐색할 수 있도록 구성

**5.2 연동 외부 서비스**

  *  농촌진흥청 포털 바로가기

  *  공신력 있는 병충해 정보 및 관리 방법 제공

  *  Google 검색 바로가기

  *  질병명 기준으로 검색 결과 제공

**5.3 사용자 편의성**

  *  앱 내부 결과 확인 → 외부 상세 정보 탐색으로 자연스럽게 연결

  *  병충해 원인, 증상, 예방 및 관리 방법을 빠르게 파악 가능
