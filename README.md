# 병충해 진단 프로그램 제작 ver2

----------------

## 프로젝트 소개
>이 프로젝트는 병충해 진단 서비스를 애플리케이션으로 구현해봄으로써 일반인들이 간편하고, 편리하게 농사와 같은 업무에 도움이 되고자 개발하였다.

## 진행 과정
### 1. 주제 선정 이유
> 휴대폰에서 앱을 통해 간단하게 식물의 상태를 알아보고 사용자에게 유용한 정보를 제공할 수 있는 앱을 구현하고자 하였다.

### 2. 사용한 데이터 및 언어&플랫폼
> 선정한 데이터
* 'kaggle'에서 가져온 [New Plant Diseases Dataset](https://www.kaggle.com/datasets/vipoooool/new-plant-diseases-dataset?resource=download)을 참고하여 식물의 상태에 대한 정보를 제공하였다.

> 선정한 언어
1. Python 
  *  파이썬은 Google Colab을 통해 병충해 진단에 필요한 AI 모델을 만들고 학습시키는데 사용.

2. Dart/Flutter
  *  모델의 진단 결과를 사용자에게 보여주는 크로스 플랫폼 모바일 앱 (사용자 인터페이스)을 만드는 데 사용.

> 선정한 플랫폼
1. Google colab
  *  딥러닝 모델 개발 및 학습 환경 제공하고, 병충해 진단 모델(CNN 등)을 효율적으로 구축하고 학습시킬 수 있기에 사용.

2. VSCODE
  *  Flutter 확장 기능을 사용하여 병충해 진단 앱의 Dart 코드 작성, 디버깅, 실시간 미리보기(Hot Reload) 등의 기능으로 효율적인 크로스 플랫폼 앱 개발이 간편.

### 3. 프로젝트 진행 정도
> 병충해 진단 앱 개발 프로젝트 진행 과정
1. 데이터 확보 및 준비 : AI 모델 학습을 위한 데이터셋 준비

2. 모델 구축 및 학습 : 병충해 이미지를 인식하고 분류하는 AI 모델 형성

3. 모델 최적화 및 저장 : 학습된 모델을 실제 서비스 환경에 맞게 변환
  
4. 앱 개발 및 UI/UX 구현 : 사용자가 상호작용할 수 있는 인터페이스 개발

5. 모델 연동 및 테스트 : 앱이 백엔드/API를 통해 모델을 성공적으로 호출하는지 확인

6. 최종 테스트 및 배포 : 전체 시스템의 안정성과 사용자 경험 검증 후 앱 배포
